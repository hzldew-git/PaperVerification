# Number-field theta and Mellin modules

The theta, Poisson, and Mellin components in this directory adapt code from
[`mathlib-initiative/sum_product`](https://github.com/mathlib-initiative/sum_product),
commit `80e4127a67742659d521466204c6d2d7e0ca2b3f`, under Apache 2.0.
`DigammaSeries.lean` also adapts the digamma-series development from
[`anthropics/formal-math`](https://github.com/anthropics/formal-math), commit
`fbdc36bbf17d20af3fd0447c6d1a8a02773c9844`, under Apache 2.0.
Original copyright notices are retained in the source files. The license
texts are in `../THIRD_PARTY_LICENSES/`.

The project adds the regularized Dedekind zeta function, completed functional
equation, growth bound, Euler-product logarithmic derivative, Gamma and
digamma identities, and the bridges needed by the discriminant argument.
The exact theorem scope and trust dependencies can be inspected with the
project audit commands in `../README.md`.
