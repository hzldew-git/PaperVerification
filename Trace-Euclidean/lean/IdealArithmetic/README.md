# Maximal-order certificate kernel

The necessary `IdealArithmetic` modules adapt code from
[`alainchmt/CertifyingInvariantsNF`](https://github.com/alainchmt/CertifyingInvariantsNF),
commit `6c035d7123819ad79b3f37dfe27f5cdb2b658dad`, under Apache 2.0.
The license text is in `../THIRD_PARTY_LICENSES/CertifyingInvariantsNF_APACHE-2.0.txt`.

These modules interpret finite multiplication-table and local maximal-order
certificates as statements about number-field orders. The generated
certificate data and their Lean replays are in `../TraceEuclidean/`.
