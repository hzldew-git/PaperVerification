\section{Reproduction and interpretation}\label{sec:reproduction}

Keep this directory with its parent \texttt{inputs/} directory.
Run the following commands from \texttt{Trace-Euclidean}, using a licensed
Mathematica or Wolfram Engine installation:
\begin{lstlisting}[style=commands]
wolframscript -file mathematica/run.wls
wolframscript -file mathematica/run_voight.wls
\end{lstlisting}
The first command writes the table, interval and classification results.
The second checks every archived field row and can take longer. Both commands
return a nonzero exit status on a failed check. Missing output indicates an
incomplete run.

In an interactive Mathematica session:
\begin{lstlisting}[style=commands]
Get["mathematica/TraceEuclideanVerification.m"];
TraceEuclideanVerification`RunVerification[]
TraceEuclideanVerification`RunVoightIntegrity[]
\end{lstlisting}
An explicit output directory can be passed to either function. Loading the
\texttt{.m} file does not start a computation, clear user symbols, change the
current working directory or terminate the kernel.

\subsection*{Meaning of the computational checks}
\begin{itemize}
\item Logarithms, displayed $h$ values and the additional finite Gamma checks
  use 90-digit evaluation. High precision alone is not an interval proof.
\item Grid signs, cutoff constants and volume rounding use exact rational
  intervals. The arithmetic interpretation of $\beta(d)$ remains a
  mathematical input.
\item Gram matrices, roots, discriminants and Voronoi vertices use exact
  finite algebra in Mathematica. These checks trust its implementation.
\item The general covering inequalities and field-list completeness have
  separate mathematical dependencies, described in the theorem index.
\end{itemize}

\section{Section 4: formulas and exact decisions}\label{sec:formulas}

Let $n$ be the lattice rank and $d$ the degree of the totally real field.
Denote the input root-discriminant lower bound by $\beta(d)$ and set
\begin{align*}
  V(n,d)&=\dfrac{(\pi d)^{nd}}
  {\Gamma\!\left(\dfrac{nd}{2}+1\right)^{2}\beta(d)^{nd}}.
\end{align*}
The program evaluates $\log V$ to avoid numerical underflow. It retains a
pair when $V(n,d)c^{nd}\geq 1$, where
\begin{align*}
  c&=
  \begin{cases}
    1,&\text{in the classic-integral case, or if }n=1,\\
    2,&\text{in the integral case with }n\geq 2.
  \end{cases}
\end{align*}
The displayed functions are
\begin{align*}
  h_{\mathrm{classic}}(n,d)&=\dfrac{\log V(n,d)}{n},\\
  h_{\mathrm{integral}}(n,d)&=\dfrac{\log V(n,d)}{n}+d\log 2.
\end{align*}
The displayed integral $h$ value uses the second formula even at $n=1$;
the rank-one retention decision still uses $c=1$.

The input bounds are
\begin{align*}
  \beta(d)&=
  \begin{cases}
    D_{\min}(d)^{\frac{1}{d}},&1\leq d\leq 9,\\
    14,&d=10,\\
    \dfrac{14083}{1000},&d=11,\\[6pt]
    \dfrac{36347}{1000}\exp\left(-\dfrac{10667}{1000d}\right),&d\geq 12.
  \end{cases}
\end{align*}
The discriminants $D_{\min}(d)$ are listed in Table \ref{tab:discriminants}.

\subsection*{Exact grid decisions}
We bound $\arctan(1/5)$ and $\arctan(1/239)$ by 80-term alternating series.
Machin's identity
\begin{align*}
  \pi&=16\arctan\!\left(\dfrac{1}{5}\right)
       -4\arctan\!\left(\dfrac{1}{239}\right)
\end{align*}
gives rational bounds for $\pi$. The positive exponential series through
term $180$ is followed by a geometric upper bound for its tail. Endpoints
are rounded outwards to a denominator of $10^{85}$.

For even $nd$, $\Gamma(nd/2+1)$ is a factorial. For odd $nd$, the
half-integer Gamma formula expresses its square as a rational multiple of
$\pi$. Each value $V(n,d)$ is therefore enclosed by rational arithmetic.
In every grid decision the whole interval lies on one side of the threshold.
The exact endpoint comparisons also check
\begin{align*}
  4\pi e&<35
  \quad\text{and}\quad
  36.347\exp\!\left(-\dfrac{10.667}{15}\right)>2\pi e.
\end{align*}
Together with the analytical covering inequalities, these constants
restrict the search to $1\leq n\leq 34$ and $1\leq d\leq 14$. The finite
Gamma checks do not establish an inequality for all real arguments.

\section{Finite rank-one classification}\label{sec:classification}
Write
\begin{align*}
  q(x)&=x^{t}Gx
  \quad\text{and}\quad
  G=\begin{pmatrix}a&b\\b&c\end{pmatrix}.
\end{align*}
In this normalization the squared covering radius, named \texttt{rho}
in the source, is
\begin{align*}
  R(G)&=\dfrac{ac(a+c-2b)}{4(ac-b^{2})}.
\end{align*}
The enumeration uses $2\leq c\leq a\leq 7$, $0\leq b\leq c/2$ and
$R(G)<2$. An independent exact Voronoi calculation intersects rational
supporting half-planes and evaluates $q$ at every retained vertex. Its
search bound is computed from the parallelogram enclosed by the
$\pm e_{i}$ constraints. This checks each enumerated instance independently
of the radius formula.

\subsection*{Sources and cross-checks}
The archived files accompany John Voight, \emph{Enumeration of totally real
number fields of bounded root discriminant}. Bounds, archive timestamps and
file digests are listed in \texttt{inputs/voight/README.md}. The verification
uses those public copies.

Independent comparison scripts are \path{checks/classification.wls} and
\path{checks/voight_polynomial_integrity.wls}. The consolidated package
preserves the 115 classification assertions and adds the Section 4 tables
and interval calculations. The public Python checks provide a separate
implementation.

The computational supplement builds on repository revision
\begin{center}
\small\texttt{7f8ecd2c60b72437e6e958b60e40d2638237ee36}.
\end{center}
It does not change Lean theorem sources, toolchain pins or the numerical
inputs used by the released Lean project. Mathematica's exact arithmetic
and Lean's disclosed \texttt{native\_decide} compiler dependency are
different computational trust assumptions.

\subsection*{Troubleshooting}
For a missing Wolfram executable or license, check the installation and
activation. For missing inputs, restore the repository layout. For stale
results or a hash mismatch, use the matching code and inputs and rerun the
affected computations. If TeX compilation fails, check that XeLaTeX,
\texttt{latexmk}, the Latin Modern fonts and the packages in the preamble are
installed. Preserve the compiler log when investigating an error.
